# 🎭 Funny Jokes & More - Chrome Extension

Get your daily dose of humor with this delightful Chrome extension! Switch between different categories of jokes and brighten your day with just one click.

## 🌟 Features

- **5 Joke Categories**: Dad Jokes, Pickup Lines, Puns, Programming Jokes, and One-Liners
- **Modern UI**: Beautiful gradient design with smooth animations
- **One-Click Refresh**: Get new jokes instantly
- **Share Functionality**: Copy jokes to clipboard for easy sharing
- **Lightweight**: Fast loading and minimal resource usage
- **Offline Ready**: Works without internet connection

## 🚀 Installation

### From Chrome Web Store (Coming Soon)
1. Visit the Chrome Web Store
2. Search for "Funny Jokes & More"
3. Click "Add to Chrome"

### Manual Installation (Developer Mode)
1. Download or clone this repository
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode" in the top right
4. Click "Load unpacked" and select the extension folder
5. The extension icon will appear in your toolbar

## 🎯 How to Use

1. Click the extension icon in your Chrome toolbar
2. Choose your preferred joke category from the tabs
3. Click "🔄 New Joke" to get a fresh joke
4. Click "📱 Share" to copy the joke to your clipboard
5. Enjoy and share the laughter!

## 🛠️ Technical Details

- **Manifest Version**: 3 (Latest Chrome Extension standard)
- **Permissions**: Minimal permissions for enhanced security
- **Framework**: Vanilla JavaScript (no dependencies)
- **Design**: Modern CSS with glassmorphism effects
- **Compatibility**: Chrome 88+ and other Chromium-based browsers
